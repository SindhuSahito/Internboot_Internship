# 🌐 Portfolio Website Builder

A modern and responsive **Portfolio Website Builder** built with **React.js** and **Firebase**. This application allows users to register, create a professional portfolio, manage projects, customize portfolio templates, and publish a personal portfolio website.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/portfolio-website-builder.git
```

Go to the project directory

```bash
cd portfolio-website-builder
```

Install dependencies

```bash
npm install
```

Create a `.env` file in the root directory and add your Firebase configuration:

```env
VITE_FIREBASE_API_KEY=YOUR_API_KEY
VITE_FIREBASE_AUTH_DOMAIN=YOUR_AUTH_DOMAIN
VITE_FIREBASE_PROJECT_ID=YOUR_PROJECT_ID
VITE_FIREBASE_STORAGE_BUCKET=YOUR_STORAGE_BUCKET
VITE_FIREBASE_MESSAGING_SENDER_ID=YOUR_SENDER_ID
VITE_FIREBASE_APP_ID=YOUR_APP_ID
```

Start the development server

```bash
npm run dev
```
